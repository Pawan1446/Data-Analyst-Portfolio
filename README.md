## Projects

### 1. [Retail Sales and Profitability Dashboard](./Excel-Retail-Sales-Dashboard)

**Tools:** Excel, Power Query, PivotTables, Pivot Charts

- Built an interactive retail sales dashboard to analyze 5,111 orders.
- Tracked **$2.33M** in sales, **$292.27K** in profit and a **12.22%** profit margin.
- Analyzed sales and profit by region, category, customer segment, ship mode and discount level.
- Identified monthly trends, top-performing products and profitability drivers.

### 2. [HR Attrition and Workforce Performance Dashboard](./PowerBI-HR-Attrition-Dashboard)

**Tools:** Power BI, Power Query, DAX

- Cleaned and modeled **14,999 employee records** using Power Query.
- Created DAX measures for attrition, retention, satisfaction, workload, promotions and tenure.
- Built an interactive dashboard to analyze employee attrition by department, salary level, satisfaction, workload and tenure.
- Created workforce risk bands to identify high-risk employee groups.

---

### 3. [Financial Transaction and Accounting Analysis](./SQL-Financial-Transaction-Analysis)

**Tools:** PostgreSQL, SQL

- Analyzed **100,000 financial transactions** using SQL views, CTEs, window functions and data-quality checks.
- Created business queries for cash flow, account performance, category analysis and payment method usage.
- Performed customer/vendor ranking, month-over-month analysis and anomaly detection.
- Calculated running net cash flow and transaction value bands.

---

### 4. [Marketing Campaign Performance Analysis](./Python-Marketing-Campaign-Analysis)

**Tools:** Python, Pandas, NumPy, Matplotlib

- Cleaned and analyzed **200,000 marketing campaign records**.
- Created metrics for CTR, estimated conversions, cost per click and cost per conversion.
- Evaluated ROI, conversion rate, engagement and cost efficiency by channel, campaign type and customer segment.
- Created visualizations for ROI trends, conversion performance and correlation analysis.
